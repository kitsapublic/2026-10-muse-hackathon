# Three-minute demonstration

1. Show the 100 synthetic patients and fixed assessment date. Explain that the protocol is invented and the current reference mode uses authored answers.
2. Open one criterion and show its original wording, executable interpretation and review state. Approve the reference set.
3. Run the baseline: 19 meet every criterion, 57 fail, 24 remain unresolved. Show evidence for one unresolved decision; missing information is not absence.
4. Raise the age limit to 80: 29 meet every criterion (+10). Restore age 75 and allow three prior regimens: 23 (+4).
5. Apply both changes: 37 (+18). Explain that four extra patients needed both changes, so individual gains cannot simply be added.
6. Show the transition matrix, criterion impact and one patient trace. Export the JSON report and CSV matrix.

Once genuine Muse responses have been measured and retained, demonstrate recorded mode with its provenance and report model quality separately from deterministic correctness. Do not present authored reference answers or synthetic transport tests as model outputs.
